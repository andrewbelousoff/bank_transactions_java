# 💳 Система Управления Банковскими Картами (REST API)

Полностью готовое backend-приложение на Java и Spring Boot для автоматизации работы с банковскими картами, переводами и ролевым доступом.

## 🛠️ Технологический стек
* **Язык:** Java 17
* **Фреймворк:** Spring Boot 3.2.4 (Data JPA, Spring Security, Web)
* **База данных:** PostgreSQL 15 (в Docker-контейнере)
* **Миграции:** Liquibase (формат YAML)
* **Безопасность:** JWT (JSON Web Tokens)
* **Документация:** OpenAPI / Swagger (`docs/openapi.yaml`)
* **Тестирование:** JUnit 5, Mockito

## 🚀 Быстрый запуск (Linux)

### 1. Поднятие базы данных в Docker
Убедитесь, что Docker запущен, и выполните команду в корне проекта:
```bash
docker compose up -d
```

### 2. Сборка и запуск Java-приложения
Проект автоматически накатит миграции Liquibase на запущенную базу:
```bash
mvn clean spring-boot:run
```
Сервер запустится на порту `8080`.

## 🧪 Тестирование бизнес-логики
Для запуска написанных юнит-тестов (проверка логики переводов, валидации баланса и владельцев карт) выполните:
```bash
mvn test
```

## 📂 Структура проекта и документация
* Спецификация эндпоинтов: `docs/openapi.yaml`
* Контроллеры ролей: `src/main/java/com/example/bankcards/controller/`
* Логика безопасности и JWT-фильтр: `src/main/java/com/example/bankcards/security/`
